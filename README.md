# 💰 Expense Tracker

A simple and responsive Expense Tracker built using HTML, CSS and JavaScript.

## 🚀 Features

- Add expenses
- Delete expenses
- Calculate total expenses
- Store expenses using Local Storage
- Data remains available after page refresh
- Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## 📚 What I Learned

- DOM Manipulation
- JavaScript Arrays and Objects
- Array Methods
- Local Storage
- JSON.stringify()
- JSON.parse()
- Event Handling
- Dynamic HTML Creation
